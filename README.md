# ghost-ai

GHOST is a local desktop AI assistant.

The desktop app is in `desktop/`. From that directory, run `npm install`, then:

- `npm run dev` starts the Vite app in a secured Electron window.
- `npm run build` type-checks and builds the renderer and Electron processes.
- `npm run lint` runs ESLint.
- `npm run test` runs Vitest.

Project context and feature specifications are in `context/`.
